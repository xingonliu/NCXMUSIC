# NcxMusic V1 完整功能清单

> 文档状态：Final Scope Baseline 1.0
> 建立日期：2026-08-05
> 用途：唯一回答“首版要做哪些功能”；PRD 与架构文档只补充行为和实现细节
> 开发顺序：以 `docs/development/NcxMusic-Development-Roadmap.md` 为唯一权威

## 1. 产品范围

NcxMusic V1 是面向 Windows 与 macOS 的开源网易云音乐桌面播放器，提供完整的基础音乐客户端、小云 AI Agent、自带工具与权限系统、长期记忆、音乐人格画像、语音指令、Dynamic Skill、MCP 和 Shell 扩展能力。

本清单中的功能均属于首版范围，除非标记为“技术门禁”或“API 门禁”：

- **技术门禁**：功能方向已确定，但必须先通过双平台可运行代码验证；失败时使用已经写明的回退，不重新进行产品访谈。
- **API 门禁**：等待 NeteaseCloudMusicApiEnhanced 全量审计给出字段、登录态和副作用契约；不代表功能被删除。
- **开发期决策**：范围已确定，但 Section 组合、像素参数或局部文案在开发对应页面时决定。

## 3. 网易云账户与游客模式

| 编号 | 功能 | V1 范围 |

| ACC-009 | 账户数据保留 | 退出登录默认保留该网易云 ID 的画像、记忆与聊天；只有显式删除本地账户数据才清除。 |

## 5. 播放器与队列

| 编号 | 功能 | V1 范围 |
| --- | --- | --- |
| PLY-001 | 唯一音频源 | AppShell 根层常驻唯一 AudioHost/`<audio>`，路由和 PlayerBar 卸载不影响播放。 |
| PLY-002 | 基础控制 | 播放、暂停、上一首、下一首、进度、音量、静音。 |
| PLY-003 | 单曲插播 | 脱离集合的单曲插入当前项之后并立即播放，作为正式队列项保留。 |
| PLY-004 | 集合播放 | 歌单、专辑、我喜欢、歌手热门歌曲等以完整集合替换队列，从点击项或第一项播放。 |
| PLY-005 | 播放全部 | 搜索或推荐模块的当前可见歌曲集合替换队列并从第一首播放。 |
| PLY-006 | 上一首语义 | 始终切到可见队列上一项，不根据播放时长重播当前歌曲。 |
| PLY-007 | 播放模式 | 列表循环、单曲循环、随机播放三种互斥模式；默认列表循环，不提供顺序播放。 |
| PLY-008 | 可见队列随机 | 进入随机时打乱真实可见队列并从第一项播放；拖动后继续按可见顺序，不保存隐藏原序。 |
| PLY-009 | 队列管理 | 新增、删除、清空、替换和拖动排序；首版不提供撤销。 |
| PLY-010 | 删除当前项 | 播放同位置接替项，末项删除后回到第一项；唯一歌曲删除或清空后停止。 |
| PLY-011 | 不可播放处理 | 轻提示并尝试下一首；同一轮不重复失败项，全队列不可播时停止。 |
| PLY-012 | 后台播放 | 路由切换、隐藏 PlayerBar和最小化窗口继续播放。 |
| PLY-013 | 关闭窗口行为 | 设置为“最小化窗口”或“退出应用”，默认最小化并继续后台播放。 |
| PLY-014 | 播放快照 | 恢复队列、当前歌曲、进度、音量、静音和模式，启动保持暂停，URL 重新解析。 |
| PLY-015 | 快照写入 | 语义变化短防抖写入；进度每 5 秒节流，并在暂停、Seek、最小化和退出前刷新。 |
| PLY-016 | 全局音质 | 自动最高可用与 9 档具体音质设置，作为所有歌曲的持久偏好上限。 |
| PLY-017 | 音质回退 | 当前账户、歌曲或设备不支持目标档位时向下回退，UI 展示实际 `actualLevel`。 |
| PLY-018 | 播放中换音质 | 重新解析媒体源，尽量保持最新进度与播放/暂停意图；过期异步结果不覆盖新操作。 |
| PLY-019 | 播放详情 | 当前歌曲、封面、完整控制、歌词和队列入口；隐藏通用 PlayerBar。 |
| PLY-020 | 沉浸歌词 | SPA 独立路由、大歌词、背景视觉和完整播放控制，可在普通/最大化/全屏窗口使用。 |
| PLY-021 | 系统媒体集成 | 系统媒体键、Windows SMTC/macOS Now Playing 进入同一 PlaybackCommand 管道；技术门禁。 |
| PLY-022 | Agent 播放回执 | 小云通过 IPC/MessagePort 投递 PlayerCommand，并等待 PlaybackCoordinator 的真实结果与快照。 |

## 7. 小云 Agent

| 编号 | 功能 | V1 范围 |
| --- | --- | --- |
| AGT-001 | 手写 Runtime | 不使用 Agent 框架，自行实现模型循环、Tool Call、状态机、取消和上下文组装。 |
| AGT-002 | 单连续会话 | 不提供多会话列表，通过分块历史和长期记忆延续。 |
| AGT-003 | 单 Active Turn | 同时只有一个活动 Turn；新消息取代并取消旧流、未执行工具和交互卡。 |
| AGT-004 | 流式回复 | Provider 上游流式在 Utility 内归一化，经 IPC/MessagePort 推送 Renderer，不建内部 SSE。 |
| AGT-005 | 并行调度 | 互不依赖只读工具最多并行 4 个；写入、播放、Shell 和安装按冲突域串行。 |
| AGT-006 | 运行限额 | 单 Turn 最多 12 轮、24 个 Tool Call、主动运行 10 分钟；审批和选择等待不计时。 |
| AGT-007 | 超时 | 音乐 API 20 秒、播放命令 10 秒、模型 90 秒无有效增量、Shell 120 秒。 |
| AGT-008 | 工具重试 | 只读临时错误最多重试 2 次；写入、播放器、Shell、安装和审批后操作不透明重试。 |
| AGT-009 | 停止与取消 | 支持用户停止、新消息替换、退出、换号和 Runtime 故障终态。 |
| AGT-010 | 退出恢复 | 未完成任务不自动恢复或重放；保留中止记录，用户手动继续。 |
| AGT-011 | Prompt 压缩 | 达到模型上下文容量约 70% 时压缩，保留安全规则、目标、未完成事项、最近消息、必要记忆和工具事实。 |
| AGT-012 | 小云人格 | 固定名称“小云”，默认简体中文，友好自然、简洁、优先给结果，复杂任务给必要进度。 |
| AGT-013 | 操作提示 | 小云播放、切歌和队列变化使用轻提示并写 Action Journal。 |
| AGT-014 | 开放式播放 | 用户明确要求“随便放点歌”等时，小云可按画像和上下文自主选歌并立即播放。 |

## 13. Shell、Dynamic Skill 与 MCP

| 编号 | 功能 | V1 范围 |
| --- | --- | --- |
| EXT-001 | Shell 平台 | Windows PowerShell `-NoProfile -ExecutionPolicy Bypass`；macOS `/bin/zsh -f`；不支持 Linux。 |
| EXT-002 | Shell 工作区 | 只能使用用户授权目录或应用默认空白工作区；模型不传任意环境变量或绝对 cwd。 |
| EXT-003 | Shell 分类 | PowerShell AST、zsh 保守模板、路径与作用域纯函数审查。 |
| EXT-004 | Shell 环境 | 最小系统环境和受控 PATH；Cookie、API Key 和凭据租约不进入子进程。 |
| EXT-005 | Shell 输出 | stdout/stderr 流式展示，每通道 1 MiB 内存上限，模型结果最多 64 KiB并脱敏。 |
| EXT-006 | Shell 取消 | 超时、取消和退出必须终止完整进程树；验证失败则首版关闭 Shell Tool。技术门禁。 |
| EXT-007 | Skill 存储 | `appData/skills/<skill_name>/`，解析 `SKILL.md` YAML Frontmatter 和 Prompt。 |
| EXT-008 | Skill 来源 | AppData 手工编辑、本地文件夹/ZIP 导入、HTTPS Git 安装；不建设公共市场。 |
| EXT-009 | Skill Tool | JavaScript 在独立 Skill Host 中动态 import，调用仍经过 PolicyGateway。 |
| EXT-010 | Skill 依赖 | 不在线安装 npm/pnpm、不执行 lifecycle、不支持 `.node`；纯 JS 依赖随包并计入哈希。 |
| EXT-011 | Skill 生命周期 | 启用/禁用、错误隔离、版本、更新、回滚；不自动更新，卸载保留 7 天。 |
| EXT-012 | MCP Client | 使用官方 SDK 稳定 v1.x，只支持 stdio 与 Streamable HTTP。 |
| EXT-013 | MCP 配置 | 设置页新增、编辑、删除、导入和导出；导出不包含凭据或可逆 Credential Reference。 |
| EXT-014 | MCP 安装审批 | 小云安装、更新、删除每次必须 ApprovalCard；用户在设置页主动操作使用普通确认。 |
| EXT-015 | MCP Tool 审批 | 所有外部 MCP Tool Call 首版逐次审批，Annotations 不参与自动放行。 |
| EXT-016 | MCP 命名 | `mcp.<serverId>.<toolName>`，外部 Tool 不能覆盖内置 Tool。 |
| EXT-017 | MCP 进程监督 | stdio 按需启动、空闲 10 分钟关闭、崩溃最多重启 3 次；HTTP 显式连接/关闭。 |
| EXT-018 | MCP 更新回滚 | 不自动更新；配置变化重新审批，更新保留上一配置，删除不触碰外部数据。 |
| EXT-019 | 旧 SSE 排除 | 不实现、不回退、不展示旧 HTTP+SSE Transport 兼容标记。 |

| --- | --- | --- |
| DAT-001 | 内嵌 API | NeteaseCloudMusicApiEnhanced 作为 Utility Process 本地依赖，不要求用户部署服务。 |

## 18. 明确不做

- Linux 版本。
- TTS、语音播报和本地/离线 ASR。
- 小云全局侧边栏、多会话列表、自定义名称/人格/回复长度。
- 支付、购买、订阅、下单和代购能力。
- MV、播客、电台、直播、商城等完整业务页面；相关 API 仍可进入只读能力目录。
- 播放队列撤销、顺序播放模式、隐藏随机顺序。
- 公共 Skill 市场、Skill 在线安装依赖、原生 Skill 模块。
- MCP 旧 HTTP+SSE Transport 和 MCP Tool 免审。
- 本地向量模型、Provider Embedding 记忆方案和普通业务数据库整库加密。
- 应用内自动更新器。
- 首版完整读屏认证与多语言界面。

## 19. 开发期允许决定的内容

以下不再继续产品访谈，由开发对应功能时在代码、Story 或 ADR 中记录：

- 各页面最终 Section 清单、顺序、尺寸、密度和局部响应式布局。
- API 审计后各 Section 的具体数据源、分页、缓存 TTL、刷新和离线降级。
- 组件像素微调、平台 Glass 降级参数、缺失业务图标和局部动效。
- Phase 0 验证后的精确依赖版本、原生二进制打包参数和媒体链路实现。
- 不改变本清单功能语义的空状态文案、说明文案和局部操作排列。

开发期决策不得扩大首版页面、注册支付能力、绕过权限、增加云端服务或改变已冻结的播放/数据语义；发生这些变化必须回到产品范围评审。
