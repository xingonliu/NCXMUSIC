# 语音识别架构

## 识别来源

语音页提供三个互斥的默认来源：

- `本地`：音频在 Renderer 中转为 16 kHz 单声道 PCM，经严格 IPC 白名单发送到独立 `localAsr` utilityProcess，不上传原始音频。
- `大模型`：使用独立的 OpenAI Audio Transcriptions 兼容配置。API Key 和自定义 Header 由 Main 使用 `safeStorage` 加密，Renderer 只能看到是否已配置及 Header 名称。
- `当前对话模型`：复用当前 Agent Provider 的 ASR 能力，强制非流式，兼容升级前行为。

新用户默认使用本地识别；已有对话 Provider 的升级用户默认保持当前对话模型。物理内存低于 8 GiB 时推荐并默认选择轻量模型，否则默认选择准确模型。

## 本地模型与资源预算

模型不进入应用安装包，首次使用时由用户点击安装。安装器支持 HTTP Range 断点续传、SHA-256 校验、临时目录解包和原子切换。可通过 `NCXMUSIC_ASR_MIRROR_BASE_URL` 配置发行方维护的国内镜像；没有镜像或镜像失败时回退 k2-fsa 官方 GitHub Release。不要将未经审计的第三方镜像写入发行配置。

| 选项 | 运行方式 | 下载 | 安装 | 经验内存 |
| --- | --- | ---: | ---: | ---: |
| 轻量 | Zipformer 小型中英 INT8，真流式 | 436.96 MiB | 57.59 MiB | 约 150 MiB |
| 准确 | SenseVoice INT8 + Silero VAD，分段增量 | 155.45 MiB | 229.07 MiB | 约 350 MiB |

轻量模型上游归档同时包含多套精度和分块版本，因此下载体积显著大于选择性安装后的体积。安装器只保留当前运行时需要的 INT8 文件。

`按需加载`在识别完成且空闲 15 秒后结束本地识别进程，确保 Native 权重内存归还操作系统；`常驻内存后台`复用已加载识别器，降低下一次启动延迟。

Windows x64 未打包目录实测新增 sherpa-onnx Native 运行时 23,062,546 字节（21.99 MiB，其中平台二进制 21.94 MiB）；模型体积不计入应用包。macOS 会按构建机器架构安装对应可选二进制，实际增量应以各平台发行产物复测，不能直接套用 Windows 数字。

## 流式语义

- 轻量本地模型边接收 PCM 边返回累计文本，属于真实流式识别。
- SenseVoice 是离线模型；开启“流式”后由 Silero VAD 切分语音段，每段完成后增量展示，不应宣传为模型原生流式。
- 独立大模型在录音结束并上传后读取 SSE 增量结果，不是麦克风音频实时上传。`whisper-1` 自动强制非流式。
- 当前对话模型只允许非流式。

## 快捷键、胶囊与通知

默认全局按住说话组合键为 `Ctrl+Shift+Q`。按下后先展示准备态，模型或录音就绪后进入倾听态；Web Audio Analyser 生成实时频谱。松开组合键，或检测到说话后连续静音 1.1 秒，会结束收音。最终转写在胶囊中展示 1.2 秒后才提交 Agent。

主窗口处于前台时使用应用内胶囊。主窗口不在前台时，Main 通过 `screen.getDisplayNearestPoint(screen.getCursorScreenPoint())` 定位鼠标所在显示器，并在该显示器 `workArea` 底部水平居中展示无焦点、无任务栏项的独立胶囊窗口。

语音启动的 Agent Turn 完成后由 Main 创建 Windows/macOS 原生通知。点击通知会恢复主窗口并打开 Agent 页面。操作系统负责在勿扰模式下抑制通知。

Electron 没有公开跨平台 API 可可靠读取 Windows 专注助手或 macOS 专注模式，也不能可靠判断任意第三方前台程序是否独占全屏。因此当前只在 Ncxmusic 自身全屏时禁用语音快捷键，macOS 外置胶囊也设置为不覆盖全屏空间；不要使用注册表或私有系统文件伪造“勿扰已检测”。
