# Prompt 36：Phase 6 音乐人格画像

执行通用协议，只实现画像初始化、增量更新和用户控制。

## 必读

- Storage Architecture、Agent Runtime。
- 功能清单 PRO-001～009/011、SET-003。
- PRD 的画像数据输入、权重、阈值、静默期、云端边界和敏感推断约束；定向读取。
- 喜欢、用户歌单、歌单全曲、播放排行、用户资料相关 Endpoint 报告。

## 任务

实现登录且模型可用时的小云输入区初始化提示，用户确认后才完整采集。对喜欢、自建/收藏歌单、添加/更新时间和播放排行做本地去重聚合；云端默认只接收聚合特征及代表样本。

实现喜欢 ×1.5、自建歌曲 ×1、收藏 ×0、同曲最高权重、30 分更新提示、关闭后 7 天静默、追加 15 分提前提示。支持证据/置信度、纠正、隐藏、补充、暂停、恢复、重新生成和删除；不得推断敏感真实人格。

## 验收

游客无画像、首次不静默、更新不静默、换号隔离、重启恢复、失败续跑和删除边界通过。输出 Checkpoint 后停止。
