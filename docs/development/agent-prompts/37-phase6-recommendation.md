# Prompt 37：Phase 6 小云个性化推荐

执行通用协议，只实现基于画像的推荐能力和最终页面装配。

## 必读

- 功能清单 PRO-010、AGT-014、MUS-001。
- 发现页当前 Section Checkpoint、Agent Runtime、Design System Section Contract。
- 已审计推荐/搜索/歌曲与歌单 Endpoint 报告。

## 任务

建立画像到候选检索、重排、证据和反馈的数据链路。小云在用户明确“随便放点歌”等开放播放意图时可自主选歌并立即播放；普通推荐展示模块不自动播放或改队列。

根据当前发现页真实内容，在本 Checkpoint 决定“小云为你推荐”的页面位置、Section 尺寸和条件。只在正式登录、模型可用、画像 `ready` 时显示；不满足条件时完全隐藏而非空壳。

## 验收

条件展示、画像证据、去重、失败隔离、用户纠正影响、展示不自动播放和开放意图真实播放 E2E 通过。输出 Checkpoint 后停止。
