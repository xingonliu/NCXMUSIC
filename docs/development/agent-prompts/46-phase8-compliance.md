# Prompt 46：Phase 8 数据迁移、隐私与开源合规

执行通用协议，只完成发布前数据与合规交付。

## 必读

- Storage Architecture、Extensions Architecture、PRD 的账户风险和云模型披露条目。
- API Audit Manifest/阻断报告。
- 功能清单 DAT-008～013、PLT-010、SET-010/011。

## 任务

验证所有 SQLite/配置 Migration、旧版本升级、损坏恢复、按账号删除、缓存清理、退出保留和卸载残留说明。审计 Cookie、Provider/MCP Secret、录音、聊天、画像、日志、Tool 参数和导出文件的数据流与脱敏。

## 验收

秘密扫描、迁移矩阵、删除验证、许可证扫描和披露审查通过。输出 Checkpoint 后停止。
