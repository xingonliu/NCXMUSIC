# Prompt 21：Phase 3 播放恢复与错误闭环

执行通用协议，只补全 Phase 3 的恢复、系统媒体和故障行为。

- Player Domain 的错误、系统媒体、后台和持久化章节。
- 存储架构、IPC Protocol。
- 功能清单 PLY-011～015、PLY-021/022、SET-005。

## 任务

正式接入播放快照：语义变化短防抖，进度 5 秒节流，关键生命周期刷新；启动恢复队列/当前项/进度/音量/模式但保持暂停，URL 重取。实现不可播放轻提示、有限自动跳歌和全队列失败停止。

接通 T-07 系统媒体实现、窗口最小化后台播放、关闭窗口“最小化/退出”设置。完善 Renderer 重载、Utility 重启和旧 generation 快照保护。

## 验收

重启、崩溃、路由、隐藏 PlayerBar、最小化、退出、失效歌曲、快速切歌和切音质 E2E 通过。输出 Checkpoint 后停止。
