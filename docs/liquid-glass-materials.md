# 液态玻璃材质规范

## 材质入口

`CommonButton`、`CommonIconButton` 使用 `material` 指定材质，颜色语义继续由 `variant` 决定。

| 级别 | material | 光学效果 | 交互 |
| --- | --- | --- | --- |
| G0 | `none` | 不增加玻璃底层 | 可以保留按压形变 |
| G1 | `frost` | 仅高斯背景模糊及语义底色，无折射或色散 | demo 按压形变和回弹 |
| G2-T | `clear` | demo 透明按钮完整材质 | demo 按压形变和回弹 |
| G2-C | `tinted` | demo 彩色按钮完整材质，采用项目主题色 | demo 按压形变和回弹 |
| G3 | `dialog` | demo Dialog 的模糊、折射、高光和深度参数 | 面板不随点击形变 |

`CommonHeaderButton` 使用 G1；Header 按钮组共用一个 G1 底层，子项不重复模糊。
图标本身保持清晰，材质作用于图标按钮底层。正文、图片和密集列表内容保持 G0。
`CommonIconButton` 的 `material="none" :liquid-press="false"` 保留普通按钮原有反馈，不挂载新材质层。

## Demo 复用边界

- 原始来源：用户提供的 `D:/code/chat/docs/liquid-glass`。
- `src/renderer/design-system/materials/demo/renderer.js` 保留原 renderer 和 shader，仅追加模块导出。
- `demo/buttons.js` 从原 `app.js` 原样提取 Spring、InteractiveHighlight、buttonDeform、drawButton 及其依赖函数。
- `glass-renderer.ts` 调用 demo 的 `drawButton`，G3 使用参考 Dialog 参数。DOM 承担整体形变，因此适配器取消重复的 shader 几何变换；光学计算仍由原 shader 执行。
- 彩色采用当前主题色；深色面板调整表面颜色与亮度。所有实例共用一个 WebGL 上下文，每个完整材质实例只保留自己的 2D 输出。
- `demo/PROVENANCE.md` 和 `demo/source-hashes.json` 记录来源与校验值。测试保护 shader 原样复用及按钮参数、形变和回弹。
- 既有 PlayerBar 的 SVG 材质继续由 `LiquidGlass.vue` 管理。

## 背景来源和生命周期

- 图片上的 G2 使用该区域实际图片，按图片尺寸、裁剪和位置映射。Hero 与电台的遮罩参与采样。
- 纯色设置背景使用真实祖先背景色合成均匀纹理，不添加装饰壁纸。
- G3 在展示前通过受信主窗口的 `webContents.capturePage()` 取得当前页面像素。图片仅在内存中供当前弹窗使用，不写盘、不上传，不捕获其他窗口。
- Dialog 底部 G2 采样已渲染的 G3 面板，不再次采样原始页面。抽屉进入动画期间更新位置；内部滚动后更新按钮采样。
- 背景捕获失败不阻止弹窗打开；快速关闭或卸载会使未完成的捕获失效。
- 图片无法读取、WebGL 不可用或快照与窗口尺寸不匹配时使用 G1；重新打开面板取得新快照。G0 不自动升级。
- 减少动态效果时取消方向拉伸；减少透明度时使用稳定底色。禁用和加载状态不触发按压形变。
- 静止时不维持逐帧动画；视口外实例不绘制。卸载时释放观察器、事件监听和动画回调。

## 通用组件测试页

在“通用组件交互测试页 → 操作类”查看 `GlassButtons`，也可搜索 `GlassButtons`。
三档均提供文字按钮、图标按钮、禁用和加载状态；可点击、按住拖动、使用键盘，点击次数可见。页面包含 G3 弹窗及其底部按钮入口。
测试区域使用 demo 附带的本地壁纸，避免外部图片加载影响对比。

## 验证范围

类型检查、单元测试、架构边界检查和生产构建覆盖接入代码。原始 shader 校验、按钮参数与弹簧收敛、Header 默认等级、异步弹窗关闭竞态有专门测试。
浏览器集成检查使用真实项目组件，验证 G1/G2/G3 渲染结果、深浅主题、抽屉以及通用测试页的三档控件；浏览器夹具的页面捕获使用固定背景适配器。真实 Electron 捕获由运行时 smoke 的 `glassBackdropCapture` 检查验证。
